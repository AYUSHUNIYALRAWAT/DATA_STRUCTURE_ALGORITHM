# Python Number Programs

A beginner-friendly collection of Python programs for practicing number-based logic, loops, conditionals, and string operations.

## Programs Included

| File | Description |
|---|---|
| `armstrong.py` | Checks whether a number is an Armstrong number. |
| `count_the_number.py` | Counts the digits in a number using different approaches. |
| `EXTRACTION_OF_NUMBER.py` | Extracts and displays individual digits of a number. |
| `palidrome.py` | Checks whether a number is a palindrome using numeric and string approaches. |
| `print_prime_factor_of_number.py` | Prints the factors of a number. Note: the current code prints all factors, not only prime factors. |

## Requirements

- Python 3.x
- No third-party packages are required for the basic scripts.

## How to Run

1. Install Python 3 from [python.org](https://www.python.org/downloads/) if it is not already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run a program, for example:

   ```bash
   python armstrong.py
   ```

   Depending on your installation, you may need to use `python3` instead:

   ```bash
   python3 armstrong.py
   ```

5. Enter the number requested by the program.

## Example

For `armstrong.py`, entering `153` should identify it as an Armstrong number because:

`1³ + 5³ + 3³ = 153`

For `palidrome.py`, entering `121` should identify it as a palindrome.

## Learning Objectives

- Practice Python input and output.
- Use `if` / `else` conditions and loops.
- Work with integer division (`//`) and remainder (`%`).
- Convert values to strings and use string slicing.
- Understand basic number-processing algorithms.

## Notes and Limitations

- These scripts are intended for learning and practice.
- Some scripts may need additional validation for zero, negative numbers, or invalid input.
- The file `print_prime_factor_of_number.py` currently lists factors; it does not filter for prime factors.
- The filename `palidrome.py` is retained to match the uploaded file. It can be renamed to `palindrome.py` later, with the README updated accordingly.
